## 核心服务栈：
系统装的飞牛，为了追求稳定所以没去尝试黑裙。

### 1. 网络底层与安全过滤
Lucky：一个强大的网络配置管理工具，我主要用它连cf的tunnel来实现内网穿透，速度挺快的能跑满我家宽带上行。

AdGuard Home：全屋的 DNS 大管家。在本地直接作为第一道过滤网，静默拦截各种设备上的垃圾广告与追踪弹窗，顺便做一下局域网内的 DNS 加速。

v2raya：更适合宝宝体质的网络代理工具，负责解决某些容器在拉取资源或更新时的网络连通性问题，总之懂的都懂。(后续估计会换成软路由)

### 2. 自动化下载
虽然不看 4K 原盘，但必要的资源留存还是得有高效的工具来跑：

Aria2-Pro + AriaNg：常驻后台的轻量级全能下载神器。配合 AriaNg 的 Web 前端，不管是 HTTP 链接还是磁力种子，都能直接跑满带宽。日常远程丢链接挂机下载，体验极佳。

qBittorrent：老牌 PT/BT 专用下载器，主要用来挂一些大文件和高质量的开源镜像。

openlist：主要用来聚合文件协议方便挂载，网页功能对我来说反而没那么常用。

飞牛自带的下载器：在不好获取直链时候(比如Onedrive的分享就不是直链)，可以在手机上进入飞牛app的下载器的管理页面，右上角有个浏览器按钮，打开后再访问要下的资源点击下载按钮就能自动识别并下载了。飞牛官方也提供免费的内网穿透功能，所以可以远程访问飞牛app控制主机下载文件，总体使用起来还是很方便的。

### 3. 数据同步与音频服务
Rclone：这台服务器的“超级运油车”。配合自建的各种存储后端，我用它来直接挂载和管理云端账户。通过流式传输（Streaming）在本地、VPS 和云盘之间互通资源，不吃本地存储，也不占多余的临时空间。

Navidrome：我不怎么看大片，但我离不开音乐。这是极其轻量级的自建音乐流媒体服务。内存占用低到可以忽略不计，配合第三方手机客户端，串流自己的音乐库。

### 4. 图书管理系统
Talebook：基于Calibre的开源图书系统，界面看着很舒服，还有一大堆神奇的小功能(比如在线编辑元数据、刮削、导入和制作有声书等，还支持社区插件)，总之用起来还是很舒服的。

Komaga：老牌漫画管理器了，唯一缺点就是内存占用的有些多了（使用时能占到800多M)，但我也没怎么用过别的管理器，或许这是正常现象吧

### 5.其他
青龙面板：主要用来跑些论坛的签到脚本

## 结尾
正如我开头所说，虽然这台nas配置不高，但对我来说完全够用，在跑了6、7个docker和一些本地服务的情况下，cpu占用也只有个位，内存占用也只有35%左右。之后我也会继续摸索nas的相关玩法，以上。
